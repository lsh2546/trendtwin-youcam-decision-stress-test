# Two-minute recording card

Record the deployed or local app at 1920×1080. Keep the cursor deliberate and use no copyrighted music.

| Time | Screen and action | Required visible message |
|---|---|---|
| 0:00–0:10 | Play the opening sequence | `WHAT IF SAND STAYS?`, `FAILURE DETECTED`, `REJECT` |
| 0:10–0:30 | Enter the app and select the Sand counterfactual | `Decision Hypothesis` |
| 0:30–0:50 | Open Customer Twins | Seoul, Tokyo, Taipei and skin-tone coverage |
| 0:50–1:15 | Run the VTO stress test | `CONTROL` versus `COUNTERFACTUAL` |
| 1:15–1:35 | Open the conflict map and switch the metric | Sand failure and Taipei low conflict |
| 1:35–1:55 | Open Decision Report | Decision A `REJECT`; B and C `APPROVE` |
| 1:55–2:00 | Present the final verdict | `One simulation prevented one expensive mistake` |

Before upload:

- Export as MP4/H.264, 1080p, 30 fps.
- Add `DEMO_SUBTITLES.srt`.
- Verify the runtime is between 1 and 3 minutes.
- Set YouTube visibility to Public or Unlisted and test the URL while signed out.
- Do not show API keys, personal data, browser bookmarks, or notifications.
